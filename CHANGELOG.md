- 2026-10-17: 9B download loop fixed: Lumen's own downloader (`ModelFiles`) fetches the model files 4 at a time with up to 6 tries each, big files in 32 MB pieces, checks every file against tensor-cache.json before and after saving, checks the free space first and asks for persistent storage. A broken saved file is downloaded again on its own (never the whole model); a stale tensor-cache.json is replaced; a browser that damages files in the Cache API is switched to OPFS; at most 2 repairs per start and 4 per day; Pause download; carries on by itself when the internet is back; switching models during a download starts the new one at once. `index.html` (engine, model files).
